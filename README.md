# AUV Six-DOF Simulation

This project contains a modular Python simulation of a REMUS-style autonomous underwater vehicle (AUV) with six degrees of freedom (6-DOF). It reproduces the hydrodynamic model documented by Prestero (2001) and layers guidance, control, and visualization to evaluate pitch/yaw autopilots.

## Project Layout
- `auv_sim/`
  - `dynamics.py`: 6-DOF equations of motion and hydrodynamic coefficients.
  - `control.py`: PID controllers for pitch (`theta`) and yaw (`psi`).
  - `guidance.py`: Step-wise command generators for depth/pitch and yaw.
  - `integrators.py`: Runge–Kutta 4 integrator.
  - `runner.py`: Closed-loop simulation orchestrating guidance, control, and plant.
  - `plotting.py`: Plot utilities (e.g., longitudinal response).
- `main.py`: Entry point that runs one simulation and stores artifacts under `runs/`.
- `docs/`: Additional documentation (`x_tail_conversion.md` for X-tail notes).
- `runs/`: Auto-generated folders with time-stamped outputs (plots, logs).

## Physics Snapshot
- **State vector** `X = [u, v, w, p, q, r, x, y, z, \phi, \theta, \psi]^T`
  - Body-frame linear velocity `\nu = [u, v, w]^T` and angular rate `\omega = [p, q, r]^T`.
  - Inertial position `\eta_p = [x, y, z]^T` expressed in North-East-Down (NED).
  - Euler attitude `\eta_o = [\phi, \theta, \psi]^T` (roll, pitch, yaw).
- **Inputs** `\tau = [\delta_e, \delta_r]^T`: stern-plane (elevator) and rudder deflections in radians.
- **Vehicle parameters**: Stored in `AUVHydroParameters`, containing buoyancy/weight, added-mass terms, damping coefficients, and actuator gains copied from Prestero (2001).

## Dynamic Equations Used in `dynamics.py`

The implementation follows the standard marine craft model (Fossen 2011):

\[
\mathbf{M}_RB \dot{\nu} + \mathbf{M}_A \dot{\nu} + \mathbf{C}(\nu) \nu + \mathbf{D}(\nu) \nu + \mathbf{g}(\eta_o) = \tau
\]

For clarity the code builds the **effective mass matrix** `M` that already combines rigid-body and added-mass terms, and solves `M \dot{\nu} = F`, where:

- `M` is the 6×6 matrix defined in lines 112–135 of `dynamics.py`. Each entry comes from Prestero's Appendix C (e.g., surge added-mass `X_du`, sway `Y_dv`, pitch inertia `Iy`).
- `F = [F_1, \ldots, F_6]^T` contains the generalized forces and moments:
  - `F1` (surge) combines axial thrust, drag `X_{u|u|}`, cross-coupling from heave/yaw, and gravity/buoyancy.
  - `F2` (sway) and `F3` (heave) include quadratic damping terms `Y_{v|v|}`, `Z_{w|w|}` and control-surface effects `Y_{u^2 \delta_r}`, `Z_{u^2 \delta_e}`.
  - `F4`, `F5`, `F6` represent roll, pitch, and yaw moments generated by off-center weight/buoyancy pairs, gyroscopic products of inertia, damping (`K_{p|p|}`, `Mq|q|`, `Nr|r|`), and stern-plane/rudder commands.

Each term is coded explicitly in the `F1`–`F6` blocks to mirror the analytical expressions:

```113:205:auv_sim/dynamics.py
    F1 = (-(W - B) * sin(theta) + X_{u|u|} |u| u + ... + X_T)
    F2 = ((W - B) * cos(theta) * sin(phi) + Y_{v|v|} |v| v + ... + Y_{u^2 \delta_r} u^2 \delta_r)
    F3 = ((W - B) * cos(theta) * cos(phi) + Z_{w|w|} |w| w + ... + Z_{u^2 \delta_e} u^2 \delta_e)
    F4 = (... + K_{p|p|} |p| p + ... + K_T)
    F5 = (... + M_{u^2 \delta_e} u^2 \delta_e)
    F6 = (... + N_{u^2 \delta_r} u^2 \delta_r)
```

### Kinematic Mapping

Once accelerations `\dot{\nu}` are computed, the translational and rotational kinematics map body-frame velocities to inertial rates:

\[
\dot{\eta}_p = R(\eta_o) \nu, \qquad \dot{\eta}_o = T(\eta_o) \omega
\]

where `R` is the standard rotation matrix from body to NED using yaw–pitch–roll ordering, and `T` is the Euler-angle transformation (see lines 207–231 in `dynamics.py`). The code writes each component explicitly, e.g.,

```207:231:auv_sim/dynamics.py
    x_dot = cos(psi) cos(theta) u - sin(psi) cos(phi) v + ...
    phi_dot = p + sin(phi) tan(theta) q + cos(phi) tan(theta) r
```

### Control Model

Elevator and rudder commands generated by the PID loops produce forces through the coefficients `Z_{u^2 \delta_e}`, `M_{u^2 \delta_e}`, `Y_{u^2 \delta_r}`, and `N_{u^2 \delta_r}`. These terms approximate lift from stern planes proportional to `u^2` and the commanded deflection. Thruster surge `X_T` and constant roll torque `K_T` represent the propeller effects used by Prestero to trim the REMUS vehicle.

## Extending the Model
- Adjust controller gains or guidance profiles in `control.py` and `guidance.py`.
- Modify vehicle parameters via `AUVHydroParameters` in `dynamics.py`.
- Implement different actuator layouts (e.g., X-tail) by adding control allocation (see `docs/x_tail_conversion.md`).
- Add new plots or logging by expanding `plotting.py` or `runner.py`.

For a deeper dive into the actuator assumptions and conversion to X-tail control, consult `docs/x_tail_conversion.md`.
